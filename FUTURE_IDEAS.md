# Future Enhancement Ideas

This document collects potential features and improvements for the Modern Mermaid plugin.

## 1. Export Options

- Export diagrams as SVG, PDF formats
- Direct save to file button
- Multiple resolution options (1x, 2x, 3x)

## 2. Advanced Styling

- Custom theme color configuration
- Font size and type settings
- Line weight, color, and detailed style customization

## 3. Diagram Size Control

- Fixed height option
- Zoom in/out functionality
- Real-time size adjustment handles

## 4. Version Management

- Lock to specific Mermaid version
- Disable auto-update option
- Use beta/test versions

## 5. Automatic Theme Detection

- Auto-switch mer/merdark based on Obsidian theme
- Default theme selection in settings

## 6. Diagram Templates

- Save frequently used diagram types as templates
- Quick insert commands
- Template library

## 7. Large Diagram Optimization

- Virtual scrolling support
- Lazy loading
- Partial rendering

## 8. Diagram Navigation

- Pan/zoom functionality ✅ **COMPLETED** (v2.1.0)
- Mini-map
- Quick search/highlighting

## 9. Animation Effects

- Enable Mermaid animations
- Custom animation settings

## 10. Diagram Links

- Click nodes to navigate to other notes
- Internal link support
- External URL connections
